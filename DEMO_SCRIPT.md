# 30-second demo script

> "I've been studying how AI agents might troubleshoot software outages more reliably. I built Failure Atlas to organize real engineering postmortems, with links to the original evidence. Here you can describe a symptom and see which historical incidents share related terms. It's deliberately simple keyword matching, not a trained AI model. The deeper research asks whether giving these reports to an AI improves its answers. I've prepared the test and verified the files, but I haven't run real model comparisons yet. So I'm showing what works and what hasn't been proven."

## Demo flow

1. Open index.html.
2. Choose "Database issue" under Try.
3. Show the retrieved GitHub incident and its original postmortem link.
4. Scroll to Evidence and point out "Not yet demonstrated".
5. Ask your listener what they would want to test next.

## One-sentence portfolio description

"Built a source-linked, privacy-safe troubleshooting incident explorer with deterministic search, reproducible data provenance, automated tests, and explicit separation of tested behavior from unverified AI-performance claims."
